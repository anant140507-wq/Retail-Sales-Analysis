# Retail-Sales-Analysis
Beginner-level retail sales data analysis using Python, Pandas and Matplotlib.
Retail Sales Data Analysis

Project Overview

A beginner-level data analysis project using Python to explore retail sales, product performance, city-wise revenue and monthly sales trends.

Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab

Dataset

A sample dataset containing 20 retail transactions across three cities and four product categories.

Analysis Performed

- Dataset exploration
- Data cleaning
- Product-wise revenue analysis
- City-wise sales comparison
- Monthly revenue analysis
- Data visualization
- Retail sales dashboard creation

Key Findings

- Total Revenue: ₹5,12,000
- Total Units Sold: 29
- Average Transaction Value: ₹25,600
- Highest Revenue Product: Laptop
- Highest Revenue City: Delhi
- Highest Revenue Month: March

Files

- "Retail_Sales_Analysis.ipynb" — Python analysis notebook
- "sales_data.csv" — Sample sales dataset
- "retail_sales_dashboard.png" — Final dashboard

Skills Demonstrated

Python, Pandas, data cleaning, exploratory data analysis, data aggregation and visualization.

Note

This project uses synthetic sample data for educational purposes. It does not represent actual business transactions.
